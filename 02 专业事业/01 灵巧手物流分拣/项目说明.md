# 灵巧手物流分拣 · 项目说明

## 项目目标与边界

围绕 NERO 双臂物流分拣，通过文献调研与平台验证确定研究问题，形成可复现的真机实验，争取投稿 IROS 2027。目标会议日期和投稿要求以正式通知为准，核查后再记录，不预填时间节点。

本项目管理研究规划、硬件资料、文献分析、相关知识、实验成果和推进过程。框架阶段只明确内容归属与组织规则，不预先锁定具体研究方向、模型、设备配置或实验方案。

## 设计思想

### 1. 任务规划与时间解耦

项目规划围绕目标和任务组织，先说明要完成什么、依赖什么、交付什么、怎样算完成。日期不是任务分类依据，不按“第一周、第二周”拆解长期目录。

实际执行日期、当天进展、讨论和阻塞保存在项目记录中，并链接回对应任务。确有外部截止日期时，可在任务中注明日期与依据；调整执行时间不应迫使重写任务结构。

### 2. 知识积累与推进记录分开

硬件平台、文献与工程项目、基础知识保存可持续维护和复用的内容；项目记录保存某个时间点发生了什么、做了什么以及为什么调整。

每个对象保留一份主笔记，使用标签和链接交叉引用。日志引用主笔记，不反复复制规格、论文摘要和知识解释。过程中的发现经核查后更新主笔记，日志保留当时的上下文。

### 3. 实验研究与日常日志分开

实验研究按研究问题和实验组织，保存假设、设计、配置、数据版本、结果和结论，使他人能理解并复现。项目记录按日期组织，只记推进情况并链接实验，不承担完整实验档案的职责。

候选方向及其证据放在实验研究中；是否继续投入、需要完成哪些验证任务反映到项目规划；作出决定的讨论经过保存在项目记录中。

### 4. 先建立边界，再按需求填充

项目采用六个内容分区；硬件下按设备与系统分类，文献下提供通用刊物及主题索引。不预铺设备型号、方法清单、刊物年份目录、概念卡片和周计划。重复出现的内容需要才增加子目录、索引或模板。

编号用于固定同级目录顺序，不表示执行阶段、进度或优先级。项目说明保持稳定，解释结构与用法，不变成每周工作台。

## 目录说明

```text
01 灵巧手物流分拣/
├─ 项目说明.md
├─ 01 项目规划/
├─ 02 硬件平台/
├─ 03 文献与工程项目/
├─ 04 基础知识/
├─ 05 实验研究/
└─ 06 项目记录/
```

| 目录 | 保存内容 | 组织依据 |
| --- | --- | --- |
| `01 项目规划` | 目标拆解、任务、依赖、分工、交付物、完成标准和当前安排 | 目标与任务 |
| `02 硬件平台` | 平台配置、接口、兼容性、标定、验收结果与限制 | 设备或系统 |
| `03 文献与工程项目` | 论文主笔记、工程项目分析及按需建立的索引 | 一项工作一份主笔记 |
| `04 基础知识` | 概念、原理、方法及其对项目的意义 | 主题 |
| `05 实验研究` | 候选假设、最小验证、实验设计、运行记录、对比与研究结论 | 研究问题与实验 |
| `06 项目记录` | 推进日志、讨论纪要、决策经过、阶段回顾 | 日期与事件 |

论文的刊物、年份、主题作为属性或索引维度，不为同一论文建立多个副本。预印本、会议版本和期刊扩展优先在主笔记中说明版本关系；有必要独立分析时保留明确关联。

## 使用流程

1. **明确任务**：在项目规划中定义目标、依赖和完成标准，必要时确定负责人。
2. **积累依据**：查阅或建立硬件、文献、知识主笔记，记录来源和待核查问题。
3. **设计并执行验证**：在实验研究中形成假设、实验方案与可追溯的结果。
4. **记录推进过程**：在项目记录中记下实际进展、讨论、阻塞和决定，链接任务及有关实验。
5. **反馈到主记录**：更新规划中的任务状态、知识主笔记中的结论和下一步实验，避免在日志中维护唯一的当前状态。

任务可以有时间安排，但任务本身始终按目标组织；知识笔记可以有更新日期，但内容本身始终按主题组织。

## 最低记录要求

- 任务写清目标、依赖、交付物和完成标准；未明确的部分如实标注。
- 日志建议命名为 `YYYY-MM-DD 主题.md`，记录事实、讨论结论、下一步和关联链接。
- 实验使用可区分的名称或 ID，保留代码、环境、配置、数据、权重、评测条件和结果位置；详细字段在实际需要时形成模板。
- 性能、价格、开源状态及硬件兼容性注明来源和核查日期，不把待核查信息写成确定事实。
- 区分作者主张、论文证据、我们的判断和真机验证；每项结论说明依据与适用条件。
- 决策记录保留问题、备选方案、证据、决定和重新评估条件，当前有效安排同步回项目规划。

## 双人协作

负责人和交付物写入具体任务；讨论、交接与阶段回顾写入项目记录。重要结论交叉复查，避免各自维护同一对象的不同副本。具体人员分工在确认后填写，不由目录结构固定。
