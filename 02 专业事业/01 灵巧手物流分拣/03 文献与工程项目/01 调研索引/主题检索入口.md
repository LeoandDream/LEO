# 主题检索入口

下列为检索词建议，不代表已确定研究方向或已有研究结论。将任务词、方法词和评测词组合检索，再判断论文与项目的关系。

| 主题 | 中文关注点 | 英文起始检索词 |
| --- | --- | --- |
| 物流分拣 | 杂乱抓取、分类放置、包装材质 | robotic sorting, bin picking, cluttered grasping |
| 双臂操作 | 分工、交接、同步 | bimanual manipulation, dual-arm coordination, handover |
| 灵巧操作 | 接触、触觉、末端选择 | dexterous manipulation, tactile sensing |
| 学习策略 | 模仿学习、视觉语言动作、多视角 | imitation learning, vision-language-action, multi-view policy |
| 数据 | 示教、数据生成、数据效率 | demonstration, synthetic demonstrations, data efficiency |
| 仿真与迁移 | 场景构建、域随机化、迁移 | simulation, domain randomization, sim-to-real |
| 可靠性与评测 | 失败检测、恢复、连续运行 | failure detection, recovery, long-horizon evaluation |

检索发现先写入论文主笔记；形成任务再进入项目规划，形成可检验的假设再进入实验研究。
