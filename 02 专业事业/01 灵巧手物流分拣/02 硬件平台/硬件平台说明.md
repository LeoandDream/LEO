# 硬件平台说明

## 目录分工
| 目录 | 通用调研范围 |
| --- | --- |
| `01 机械臂与双臂集成` | 型号与交付配置、工作空间、负载、控制接口、双臂坐标与同步 |
| `02 灵巧手与末端执行器` | 夹爪、灵巧手、吸盘，机械电气接口与反馈能力 |
| `03 相机与视觉` | 相机、安装位置、标定、时间同步及数据接口 |
| `04 算力与计算环境` | 本地控制与推理、云训练、依赖环境及计算成本 |
| `05 工位与系统集成` | 桌面、料箱、物体清单、工位布局、整套系统连接与验收 |

## 记录方式
每个实际设备或系统建立一份主笔记，记录来源、核查日期、已知条件与待确认项。规格表和兼容性结论留在主笔记，实验结果与推进日志通过链接关联。

目录仅表示调研分类，不代表已购买、已选型或已验证。跨设备集成问题以系统集成笔记为主，链接相关设备。

当前先建立分类，不填充具体型号参数与价格。
