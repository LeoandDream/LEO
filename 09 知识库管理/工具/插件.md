
| 插件名称                       | 说明                                                                   |
| -------------------------- | -------------------------------------------------------------------- |
| **Dataview**               | 数据视图插件，用于在笔记中创建复杂的数据库查询和统计，适合数据管理爱好者。<br>--用于报表等可视化等，可与多个块的数据建立联系    |
| **Editing Toolbar**        | 编辑工具栏插件，提供类似 Word 的浮动工具栏，内置多种编辑命令，方便鼠标操作。<br>--提供快速编辑边框，包含字体加粗、斜体等功能 |
| **Image Tools**            | 图片工具插件，用于格式化页面中的图片（如调整大小、对齐等）。 <br>--可以直接拖拽图片右下角来调整图片大小。             |
| **Minimal Theme Settings** | 极简主题设置插件，用于自定义 Minimal 主题的颜色、字体和功能选项。<br>--获取更多主题。                   |
| **Slash Cmd**              | 斜杠命令插件，输入 `/` 调出快速菜单，可插入标题、表格、标注、代码块、列表等。<br>--图形化操作markdown语法内容     |
| **Style Settings**         | 样式设置插件，提供界面用于调整主题、插件和代码片段的 CSS 变量，实现深度自定义。                           |
