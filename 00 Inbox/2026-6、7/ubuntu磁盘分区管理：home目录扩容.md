##### 5./home 目录全量迁移（核心步骤）

**步骤 1：核验分区信息**
按 `Ctrl+Alt+T` 打开终端，执行以下命令，确认分区设备名与你的实际情况匹配：
bash运行
```
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT
```

核对标准：
- `/dev/nvme0n1p6`：约 366GB，`ext4` 格式，无挂载点 → 系统根分区
- `/dev/nvme0n1p7`：约 65GB，`ext4` 格式，无挂载点 → 原独立 /home 分区
- 所有 `ntfs` 格式的分区为 Windows 数据盘，**全程绝对不能执行任何修改操作**

> 若编号有差异，以实际输出为准，后续所有命令同步替换设备名。


**步骤 2：挂载根分区与原 /home 分区**
bash运行
```
# 创建临时挂载目录
sudo mkdir -p /mnt/root /mnt/old_home

# 挂载系统根分区
sudo mount /dev/nvme0n1p6 /mnt/root

# 挂载原独立 /home 分区
sudo mount /dev/nvme0n1p7 /mnt/old_home
```
执行 `df -h` 确认两个分区均成功挂载后再继续。


**步骤 3：全量复制 /home 数据到根分区**
使用 `rsync` 完整迁移所有文件，保留权限、属性、软链接、ACL 等全部信息，保证数据 100% 一致：
bash运行
```
sudo rsync -aAXHv --progress /mnt/old_home/ /mnt/root/home/
```

> 关键注意：源路径 `/mnt/old_home/` 末尾的斜杠 `/` 不能省略，代表「复制目录内的所有内容」，而非复制目录本身。
> 

复制完成后，验证文件完整性：
bash运行
```
sudo diff -r /mnt/old_home /mnt/root/home
```

无任何输出则说明文件完全一致，迁移成功；少量软链接提示属于正常现象，可忽略。


 **步骤 4：修改开机挂载配置（取消独立 /home 挂载）**
Ubuntu 20.04 默认使用 UUID 标识分区，我们只需要注释掉 /home 的自动挂载行即可：
bash运行
```
sudo nano /mnt/root/etc/fstab
```

在文件中找到挂载点为 `/home` 的那一行，格式类似：
```
UUID=xxxx-xxxx-xxxx-xxxx   /home   ext4   defaults   0   2
```

**在行首添加 `#` 注释掉该行**（不要直接删除，留作回滚备份）。
按 `Ctrl+O` 保存，回车确认文件名，再按 `Ctrl+X` 退出编辑器。


**步骤 5：卸载分区，重启电脑**
bash运行
```
sudo umount /mnt/root /mnt/old_home
reboot
```
重启时拔掉 U 盘，正常从硬盘启动 Ubuntu 20.04 系统。



##### 6.验证扩容结果
进入桌面后，打开终端执行：
bash运行
```
df -h /home
```

若输出满足以下两点，即为迁移成功：
1. 总容量约为 366GB（与根分区大小一致），挂载点显示为 `/`
2. 桌面文件、软件配置、浏览器书签、开发环境均和操作前完全一致

> 原 65GB 的独立分区数据并未删除，可先保留作为备份，确认系统稳定运行 1-2 天后再回收空间。



##### 7.（可选）回收旧 /home 分区，合并到根分区
确认迁移无误后，可将闲置的 65GB 分区合并进根分区，彻底用完所有磁盘空间。**此操作必须在 U 盘试用环境下完成**。

1. 重新用 U 盘启动进入试用环境，打开终端安装 GParted：
bash运行
```
sudo apt update && sudo apt install gparted -y
sudo gparted
```
2. 右上角选择磁盘 `/dev/nvme0n1`。
3. 找到 `/dev/nvme0n1p7`（原 65G home 分区），右键 →「删除」，确认后变为未分配空间。
4. 找到 `/dev/nvme0n1p6`（根分区），右键 →「调整大小 / 移动」。
5. 拖动分区右侧滑块向右拉满，吃掉所有未分配空间。
6. 点击顶部绿色对勾按钮，确认后执行操作，等待完成即可。
7. 操作完成后重启，执行 `df -h /` 可看到根分区总容量已增加。



##### 8.故障回滚方案
若重启后出现登录循环、桌面异常等问题，可一键恢复到操作前状态：

1.重新用 U 盘启动进入试用环境，挂载根分区：
bash运行
```
sudo mount /dev/nvme0n1p6 /mnt/root
```

2.编辑 fstab，恢复原 /home 挂载：
bash运行
```
sudo nano /mnt/root/etc/fstab
```

删除 /home 行前的 `#`，取消注释，保存退出。

3.卸载分区并重启：
bash运行
```
sudo umount /mnt/root
reboot
```

重启后即可完全回到操作前的状态，原独立分区的数据完整保留，无任何丢失。


##### 9.u盘复原

- Win+X → 打开 **磁盘管理**
- 下方找到你的 U 盘磁盘（区分：看容量，标注「可移动」，有多块小分区）
- 右键 U 盘每一个分区 → **删除卷**，全部删完，整块 U 盘变成「未分配」
- 右键未分配区域 → **新建简单卷**，一路下一步
- 文件系统选 **exFAT**（Windows+Mac 通用）/NTFS（仅 Windows），勾选快速格式化，完成
    
    此时 U 盘恢复完整容量，变回普通存储 U 盘。

弹出是否格式化的提示，选择是，格式化完成后恢复为正常存储盘。
