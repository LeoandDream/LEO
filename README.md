# LEO

以人生方向组织的个人知识库，使用 Obsidian 阅读和维护。

## 顶层结构
```text
00 Inbox/         收件箱
01 个人成长/       学习、技能、工具与方法
02 专业事业/       工作与项目
03 财富投资/       资产总览与交易系统
05 生活健康/       生活与健康
06 认知思维/       模型与方法论
07 资源模板/       集中维护模板与公共片段
08 归档/           历史记录与旧版设计
09 知识库管理/     架构、规范与公共数据
pictrues/         既有图片素材
.obsidian/        Obsidian 配置
```

工具使用内容已并入个人成长的 `工具与方法/`，保留其他目录原编号。

## 使用方式
1. 在 Obsidian 中打开仓库，从 [[首页]] 进入。
2. 新信息先记入 Inbox，再整理到领域项目。
3. 已有项目的 `项目说明.md` 解释目录、流程及模板入口。
4. 所有复用模板放在 `07 资源模板`，实际记录保存在项目中。

## 设计原则
先记录、再整理；按需求发展目录；沉淀可复用信息；模板保持简洁。详细约定见 [[LEO知识库构建思路]]。

## 同步
使用 Git 管理版本；本地界面状态、缓存等按现有 `.gitignore` 排除。
